# Still Life

stilllife.nino.studio — a parody group chat with famous dead artists (and, at /designers, dead designers). By Nino Studio, Seattle.

- `index.html` — What Would Dead Artists Do (Seattle palette)
- `designers/index.html` — What Would Dead Designers Do
- `og.png`, `designers/og.png` — link preview images
- Plain static files, hosted on Vercel. No build step.
